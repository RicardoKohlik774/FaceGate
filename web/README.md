# web

One React + TypeScript app (Vite) with three areas:

| Route | For whom | What |
|---|---|---|
| `/register` | New customer | BankID login, terms, plan, payment, face consent, live selfie. |
| `/account` | Customer | Own membership, visit history, fallback entry code, delete account. |
| `/admin` | Staff | Who is inside, entry history, statistics, user management, CSV export. |

The app has no business logic of its own. It calls the backend API.

UI text is Czech where it makes sense. Code is English.
